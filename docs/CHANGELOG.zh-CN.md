# 变更摘要

## 1.5.2（待发布）：UDP 免配对

移除主机网页和屏幕配网中的配对码，以及 UDP 配对码校验。旧配置中的 token 自动忽略；新版屏幕接受旧主机数据，升级顺序为先屏幕、后主机。应用分区升级保留 Wi-Fi 和显示设置。连接页与数据页统一显示 WAIT DATA / UDP LIVE / UDP STALE / OFFLINE，区分 Wi-Fi 连接与有效数据接收。保留协议版本、长度、字段及数值校验，USB 握手确认和网页登录认证保持不变。

上位机版本为 1.5.2，提供 Debian 与 fnOS 安装候选。免配对固件已完成现有屏幕应用升级，用户确认 UDP 显示正常；全新设备首次烧录尚未验收。当前改动尚未发布，dist 和 assets/UI5.1 固定发布输入仍为旧版本，新主机不可搭配其中的旧 UDP 固件。

## 交付修订 r5

补齐全新 AMOLED 屏幕首次完整烧录：固定引导程序、OTA 初始化数据、合并镜像、Windows 独立工具与 Linux/macOS 脚本。首次烧录明确清空整片 Flash，升级保持仅应用分区写入。新增独立 First-Flash ZIP 和 factory.bin，完整交付包内增加 First-Flash 目录。主机与终端版本、UI5.1 应用字节保持不变；首次烧录实机启动尚未验收。

## 交付修订 r4

使用文档统一由 docs/ 维护，补全终端入口；源码 README 明确模块职责，构建步骤集中到 BUILD。交付包简化为安装顺序与导航，终端 FPK 和交付包均取同一份终端使用说明。应用版本、运行代码、固件和机械模型保持不变。

## 交付修订 r3

应用版本保持 NAS Display 1.5.1、NAS Terminal 1.0.2；固定固件 UI5.1、外壳 V7。源码统一到 src/，硬件归入 hardware/，第三方输入归入 third_party/。更新源码运行、测试、构建、文档链接与交付路径；保留本机配置。RELEASE.json 记录交付修订，不与之前同应用版本的包按字节混用。

延续 r2 的主题文档、生成物隔离和 dist/components 交付方式；不改变产品功能或设备协议。

## 当前功能

NAS Display：统一 CPU 温度源，采集硬盘、SYS 和风扇转速；提供自动、手动百分比和温度曲线，最低输出允许 0%，已启用曲线随服务启动恢复，停止服务归还主板控制。

NAS Terminal：通过飞牛网关连接本机 SSH，支持电脑和手机交互、会话回收及独立密码。

UI5.1：AMOLED 四页布局、三套配色与字体可读性调整。V7：滑轨上盖与尾锁片外壳。
