# 远程访问与排查

NAS Display 使用 8787 端口的网页入口；NAS Terminal 使用飞牛统一网关 /app/dream-terminal，并连接 NAS 本机 SSH。两者需要已有的远程访问通路，不能修复 FN Connect 本身无法连接的问题。

FN Connect 提示无权限时，先从同一浏览器重新登录飞牛桌面并点击应用入口，对比其他应用是否可用，再检查账号权限、应用入口及网关状态。飞牛提示页不等同于 NAS Display 密码错误；不要反复修改应用密码或沿用过期的应用子域名。

IPv6 直连需要客户端具有可用 IPv6 路由、NAS 有有效公网 IPv6、服务监听 IPv6，以及路由器和上游设备允许目标入站连接。拥有公网地址不代表端口可达。DDNS 只负责把域名更新到当前地址，不能解决路由或防火墙问题。诊断时使用 ip -6 addr、ip -6 route、ss 与目标端口抓包区分问题所在。

浏览器填写 IPv6 字面量时使用方括号，例如 http://[IPv6地址]:8787。远程认证应使用受保护的 HTTPS 或已有安全访问通路。不要为排查关闭全部防火墙。

NAS Terminal 的安装、密码、SSH 及手机使用详见随包终端 README。手机 App、FN Connect 和网关兼容性取决于飞牛版本，需在目标系统验证。
