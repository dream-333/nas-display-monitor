# NAS Terminal · fnOS

开发者 / 发布者：**Dream**。

NAS Terminal 是独立安装的可选终端应用。通过飞牛统一网关打开网页终端，再连接 NAS **本机**的 SSH。适合在已有 FN Connect 登录通路上检查 IPv6、端口和系统服务。

## 安装与使用

1. 飞牛应用中心手动安装 / 升级 `NAS-Terminal-fnOS-1.0.2-x86.fpk`。升级保留终端密码和 SSH 端口，关闭旧终端连接。安装 Python 3.12 运行环境由应用中心处理；其余 Python / 前端依赖已随包提供，不需要浏览器访问 CDN。
2. 安装向导设置 **8–128 字符的独立终端密码**，填写 NAS SSH 端口（默认 22）。它不是飞牛账号密码。
3. 在飞牛系统设置中开启 SSH，并允许你要使用的 NAS 账户登录。只连接 `127.0.0.1`，无需在路由器对外开放 22 或任何新的终端端口。若 SSH 只绑定指定网卡地址而没有监听本机回环，需调整 SSH 监听设置。
4. 使用飞牛管理员账号，在应用入口打开 **NAS Terminal**。先输入终端密码，再输入 NAS 用户名，连接后按 SSH 提示输入 NAS 账户密码（不显示字符是正常现象）。
5. 运行命令；需要提权时输入 `sudo 命令`，按系统提示输入密码。

电脑：从飞牛桌面 / 应用中心打开。手机：从 App 的应用入口打开；若该版本 App 不展示第三方网页入口，可以在手机浏览器登录飞牛后打开。**手机 App WebView、FN Connect 转发及统一网关的实际支持，需要在你的系统版本上验证；本包不能修复飞牛本身无法连接的问题。**

统一网关路径为 `/app/dream-terminal`。若已登录飞牛桌面，也可将当前飞牛系统访问地址的路径改为 `/app/dream-terminal`，保持原来的协议、域名和端口。使用当前飞牛登录地址。外网使用 HTTPS。

首次试用时，请先执行 `whoami` 和 `uname -r`，再用“检查命令 → IPv6 地址与默认路由”，按 Enter 执行。可复制输出用于网络排查。

## 交互与会话

- 支持 ANSI 颜色、交互式 shell、`sudo`、`top`、终端尺寸变化。
- 手机快捷键：Esc、Tab、Ctrl、Ctrl+C、方向键、Enter。Ctrl 是下一次字符的修饰键。
- 支持 A− / A+ 字体调整，选中文字复制，粘贴前确认。多行粘贴可能执行命令，请确认后发送。
- 检查命令只填入终端，不自动回车；不包含调速或更改网络的命令。
- 短暂掉线：原页面自动重试获取输出；输出最多保留 1 MiB，超过时明确提示截断。
- 输入按序号确认，重复重试不重复写入。无法确认输入结果时停止发送，要求重新连接，避免重复执行。
- 点击“断开”结束 SSH，点击“锁定”同时销毁终端会话。关闭页面尽力通知关闭；网络断开时最多闲置 15 分钟后自动关闭。页面刷新需要重新登录。
- 最多 4 个实际 SSH 连接；解锁本身不占 SSH 名额，未连接的解锁会话两分钟自动清理。同一账号重复解锁替换尚未连接的旧令牌，不断开正在运行的 SSH。
- 达到 4 个连接时仍可解锁，在连接页面点击“关闭本账号旧连接”，确认后回收旧连接；不会关闭其他飞牛账号的终端。
- 单会话最长 8 小时；15 分钟没有终端输入会关闭，即使后台仍有输出。长任务自行使用 `tmux` / `screen`（若系统已有），本包不安装它们。
- SSH 退出、后台任务、`nohup` / `tmux` 的实际行为由 NAS 系统负责。关闭终端不是撤销已执行命令，也不能保证终止主动脱离会话的任务。

## 常见问题

- **1.0.0 提示最多 4 个终端、刷新无效：** 升级本版。旧版在解锁阶段就占用名额，新版仅在建立 SSH 时检查 4 个连接上限，并提供已认证用户的旧连接清理。
- **HTTP 200 但旧版提示飞牛登录过期：** 新版直接验证 JSON 内容，兼容代理改变响应类型；非 JSON 会显示真实 HTTP 状态，不再一律当成 401。若仍异常，请提供 `connect` 的响应正文与响应 Content-Type，不要提供 `login` 响应或请求中的密码 / 令牌。

- **应用入口无法打开 / 404：** 本应用依赖 fnOS 统一网关。先确认飞牛版本支持 `gatewayPrefix` / `gatewaySocket`。官方文档未标明最低版本，本包没有猜测兼容版本号。
- **提示请通过管理员打开：** 当前账户不是飞牛管理员，或者入口没有转发统一网关身份 Header。不会降级为匿名终端。
- **Connection refused：** 系统 SSH 未开启、端口填写错误，或 SSH 不监听回环地址。可在飞牛应用设置修改本包的 SSH 端口。
- **Permission denied：** 这是 SSH 账户 / 密码 / 登录策略问题，不是终端密码；检查系统账户是否允许 SSH 登录。本版提供密码和键盘交互认证，不提供私钥上传。
- **REMOTE HOST IDENTIFICATION HAS CHANGED：** 先核实 NAS 是否重装或 SSH 主机密钥是否确实更换，再由管理员处理应用数据中的 `state/known_hosts`；不自动绕过校验。
- **忘记终端密码：** 飞牛应用设置中填写两次新密码保存，当前会话会关闭。密码留空则保留原值。
- **飞牛 / FN Connect 自身无法连接：** 网页终端也无法连接；需要已有的飞牛远程访问通路。
