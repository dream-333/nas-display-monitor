# AMOLED 屏幕与传输

适用 LILYGO T-Display-S3 AMOLED 非触摸版，1.91 英寸、RM67162 / QSPI、ESP32-S3，横屏 536×240。当前固件 UI5.1-USB，不能使用普通 LCD 或触摸版的板定义。

## 页面与操作

三套配色、四个页面显示主机概览、散热、存储和设置。主页保留 CPU/GPU/RAM、网络与风扇信息；散热页可查看独立转速。按实际字宽缩短长磁盘名称，缺失数据显示 --。温度使用摄氏度。

短按 A 切页，短按 B 切换配色，长按 A 进入设置，长按 B 熄屏。设置行为以固件界面为准。

## USB / Wi-Fi

原生 USB-C 数据线同时供电与通信，不需要 GPIO 串口接线或 Wi-Fi 配对。在网页选择 USB 直连并启用发送。串口参数 115200 / 8N1；上位机打开端口后等待启动，完成握手、数据确认再计入发送数量。断线自动重连，恢复后发送最新采样，不补发历史队列。

Wi-Fi 使用局域网 UDP：屏幕只需配置 2.4 GHz Wi-Fi，主机填写屏幕 IPv4 地址和端口 44445，启用发送即可，不需要配对码。主机仍需正常登录管理网页。

连接页和数据页显示 `WAIT DATA`（Wi-Fi 已连接，等待有效数据）、`UDP LIVE`（数据正常）、`UDP STALE`（超过 10 秒未收到有效数据）或 `OFFLINE`（Wi-Fi 断开）。网页 UDP 发送计数没有屏幕回执，不代表屏幕已收到。

升级请先更新屏幕固件，再更新主机。新版屏幕兼容携带旧 token 的数据包；新版主机不再发送 token，旧屏幕必须升级。正常应用固件升级会保留 Wi-Fi 和显示设置，不要使用会清空配置的首次烧录流程。旧主机配置或导入文件中的 token 自动忽略，保存后不再包含该字段。

局域网内能够访问屏幕端口的设备可发送有效数据并更新画面；协议仍校验版本、长度、字段类型和数值范围。运行配置和 Wi-Fi 凭据不进入源码包。

以上免配对行为适用于当前开发源码；既有 UI5.1 发布固件仍需配对码，不能与新版主机混用。

## 全新屏幕首次烧录

使用完整交付包的 `First-Flash/`，或独立 First-Flash ZIP。引导程序、分区表、OTA 初始化数据与应用已配齐；Windows 运行 `FIRST-FLASH.cmd`。首次烧录会清空配置，详细步骤见 [首次烧录说明](FIRST-FLASH.zh-CN.md)。

## 更新已有屏幕

先暂停网页 USB 发送并关闭串口监视器。完整解压交付包后，在 Windows-x64 中运行 UPDATE.cmd，选择 COM 口；随包提供独立 esptool.exe，无需安装 Python。完成后恢复发送。

独立镜像 NAS-Display-AMOLED-UI5.1-firmware.bin 仅写应用分区 **0x10000**。要求设备已使用本项目 AMOLED 分区布局；不是空白板初始化镜像。不擦除已有配网、亮度、休眠或配色设置。已经运行 UI5.1 的屏幕无需因工程整理重刷。
