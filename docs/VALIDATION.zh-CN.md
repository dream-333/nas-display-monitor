# 当前交付验证范围

适用 NAS Display 1.5.1、NAS Terminal 1.0.2、AMOLED UI5.1、外壳 V7，交付修订 r4。

完整检查入口是 tools/check_release.py；源码交付检查是 tools/verify_source.py。每次运行生成 .build/logs，日志不随包分发，也不作为永久构建输入。

- 主机 153 项 Python 回归：温度来源、存储、通用风扇、权限、0% 曲线、重启继续与停止恢复。
- 终端 27 项回归；解包后使用实际 OpenSSH 客户端连接隔离模拟 SSH 服务，检查登录、交互、重连、断开与手机布局。
- Debian/FPK 检查载荷、摘要、权限、元数据、脚本和服务语法，并在解包后运行网页交互；不安装系统服务或写硬件。
- 源码包按白名单检查私有文件排除、CRC 和逐文件摘要，再解压执行完整构建。使用开发机已有 Python/系统工具，不代表全新操作系统的离线安装验证。
- 工程整理检查本地文档链接、旧版文件排除，以及交付 components 的目录和摘要。固件与机械发布模型沿用固定字节，重排目录不改变硬件设计。

固件历史设备反馈确认烧录、启动和 USB ACK；本次整理不烧录。机械检查为静态和离散位置采样，不等同实际装配或强度验证。

目标机真实风扇响应、fnOS 全新安装/升级/卸载、真实看门狗故障恢复、原生 Windows 烧录及不同手机 App 网关兼容性仍需实机验证。模拟结果不代表所有主板兼容。
